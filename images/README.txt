VAULTIQUE BOUTIQUE POINT — IMAGES
=================================

All site imagery lives in this folder. Everything here is OPTIONAL: the site
looks complete without any photos (it falls back to an elegant navy/gold
treatment), and you can add images over time with no code changes.

------------------------------------------------------------------
1) PRODUCT PHOTOS  (matched to the POS automatically by SKU)
------------------------------------------------------------------
Main photo, named exactly after the product SKU:
  images/MF-SUCO-BK-M.jpg
  images/WF-AUSI-CR-S.jpg

Optional extra photos for the same product (shown as gallery thumbnails on
the product page, and the "-2" image also appears on hover on the card):
  images/MF-SUCO-BK-M-2.jpg
  images/MF-SUCO-BK-M-3.jpg
  images/MF-SUCO-BK-M-4.jpg

Notes:
- Main photo may be .jpg, .jpeg, .png or .webp (tried in that order).
- Extra photos (-2, -3, -4) should be .jpg.
- SKU and filename are CASE-SENSITIVE. Match the POS exactly.
- Best look: portrait 4:5, about 800 x 1000 px, under ~300 KB each.
- If a product has no photo, an elegant "VB" placeholder is shown.

------------------------------------------------------------------
2) HERO SLIDES  (full-screen homepage banners)
------------------------------------------------------------------
  images/hero-1.jpg
  images/hero-2.jpg
  images/hero-3.jpg
Landscape, large (about 2000 x 1200 px). If absent, a refined navy/gold
gradient is shown instead, so the hero always looks intentional.

------------------------------------------------------------------
3) COLLECTION CARDS  (Featured Collections on the homepage)
------------------------------------------------------------------
Named by category, lower-cased with dashes:
  images/collection-women-s-fashion.jpg
  images/collection-men-s-fashion.jpg
  images/collection-shoes.jpg
  images/collection-bags.jpg
  images/collection-accessories.jpg
Portrait 3:4. The exact name is "collection-" + the category turned to
lowercase with non-letters replaced by dashes. If unsure, add a photo, open
the site, and adjust the filename until it appears.

------------------------------------------------------------------
4) STYLE GALLERY + EDITORIAL  (homepage lookbook tiles)
------------------------------------------------------------------
  images/look-1.jpg ... images/look-6.jpg   (square, ~800 x 800 px)
  images/editorial-1.jpg                     (square/large, the philosophy band)

All of these fall back to a navy/gold treatment when missing.
None of these images touch the POS in any way.
